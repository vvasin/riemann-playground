What a proof would guarantee

Von Koch (1901) showed that the Riemann hypothesis is equivalent to a statement about counting primes. Schoenfeld (1976) gave it in a form with explicit numbers:

If the Riemann hypothesis is true, then for every x ≥ 2657:
|π(x) − li(x)| < √x · ln x / (8π)Conversely, if this inequality holds for every x ≥ 2657, the Riemann hypothesis is true. Here π is again the circle constant.

So the hypothesis is exactly a statement about how far the count of primes can drift from the estimate li(x) of step 2. For comparison, the best bounds proven without the hypothesis are much weaker. They are smaller than x only by a factor that grows more slowly than any power of x, such as √x or x0.01.

The panel shows real values. In each case the actual error is well below the bound. For x up to about 1026 the inequality has in fact already been proven, because the zeros it depends on have been checked by computer. The hypothesis would make it true for every x.

Other consequences

  • Gaps between primes: there would always be a prime between x and x + C·√x·ln x for a fixed constant C (Cramér, 1920).
  • Many existing theorems: a large number of results in number theory have been proven under the assumption that the hypothesis holds. A proof would make all of them unconditional.

What it would not give

  • A formula that produces the primes, or the n-th prime, directly.
  • A fast method for factoring large numbers. It would not break encryption such as RSA.
  • An answer to whether a particular number is prime. That is done by primality tests.
Summary: the zeta function is a sum over all whole numbers (step 3) and also a product over primes (step 4). Its zeros (step 5) each add one wave to the prime staircase (steps 6 and 7). The size of these waves depends on the real parts of the zeros. The Riemann hypothesis says all these real parts are ½ (step 8), which is the same as saying the prime count never drifts from li(x) by more than about √x · ln x.
