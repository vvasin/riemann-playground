The zeros of zeta

A zero of ζ is an input s with ζ(s) = 0. There are two kinds:

  • Trivial zeros at s = −2, −4, −6, … They come from the functional equation, are fully understood, and play no part in what follows.
  • Nontrivial zeros, which all lie in the strip 0 < σ < 1, called the critical strip. The first one is at s = ½ + 14.1347…i.

In the panel of step 5, choose this zero and the η sum. The path closes in on 0, so η(s) = 0, and then ζ(s) = η(s) / (1 − 2/2s) = 0.

A nontrivial zero is usually written ρ = β + iγ (rho, beta, gamma). They come in mirror images: if β + iγ is a zero, then so are β − iγ, (1 − β) + iγ and (1 − β) − iγ. The panel of this step shows only the upper half (t > 0).

Key point: the nontrivial zeros of ζ are points β + iγ in the critical strip. Every one found so far has β = ½.
