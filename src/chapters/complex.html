Zeta at complex inputs

In 1859 Riemann allowed s to be a complex number, s = σ + it. σ (sigma) is the real part and t is the imaginary part.

What 1/ns means for complex s

A power with a complex exponent cannot be computed by repeated multiplication. It is defined with the number e and the natural logarithm: ns = es·ln n. For real s this is the usual power, because eln n = n. A power of e with an imaginary exponent is given by Euler's formula, eiθ = cos θ + i sin θ. Together they give

1/nσ+it = (1/nσ) · e−it·ln n,
e−it·ln n = cos(t ln n) − i sin(t ln n)The first line uses 1/nit = n−it = e−it·ln n. The second is Euler's formula with θ = −t·ln n.

Draw a complex number a + bi as an arrow from 0 to the point (a, b). An arrow of length r at the angle φ to the positive real axis is the number r·(cos φ + i sin φ). Angles are measured in radians, so a full turn is 2π. Since cos(−x) = cos x and sin(−x) = −sin x, the term 1/ns is an arrow of length 1/nσ at the angle −t·ln n. Its length depends only on σ. t only turns it.

Adding the arrows

To add complex numbers, put their arrows end to end. The panel draws the sum for ζ(s) this way, one arrow per term.

When σ > 1, the lengths 1/nσ add up to a finite total (step 3). The path then has finite length and ends at one point, the value ζ(s). When σ ≤ 1, the lengths add up to infinity, and turning the arrows does not make up for it. For σ = 1 and t ≠ 0 the path keeps going round in circles. For σ < 1 it winds outward in a widening spiral. For t = 0 all arrows point to the right and the sum grows without limit, as in step 3. In all these cases the sum has no value. So the sum defines ζ(s) only for σ > 1.

Extending zeta beyond the sum

Something similar happens with the geometric series. The sum 1 + q + q² + … works only for −1 < q < 1, but the formula 1/(1 − q) gives a value for every q except 1. For zeta, one such formula uses the alternating sum

η(s) = 1 − 1/2s + 1/3s − 1/4s + …Because the signs alternate, this sum has a finite value for every σ > 0.

In the panel, choose η: every second arrow points the opposite way, and the path closes in on one point.

For σ > 1 one can check that ζ(s) = η(s) / (1 − 2/2s). The right side also makes sense for 0 < σ ≤ 1, and that is how ζ is defined there. The bottom is 0 where 2s = 2: at s = 1 and at the points 1 ± 2πik / ln 2 for k = 1, 2, 3, … At s = 1, ζ is truly infinite. At the other points η(s) is also 0, and ζ takes the value that it approaches from nearby points. It has been proven that there is only one way to extend ζ that keeps it smooth (complex differentiable), so every correct formula gives the same values. A different formula, the functional equation, extends ζ to σ ≤ 0.

The panel marks the value ζ(s) given by this formula. For 0 < σ ≤ 1 and t ≠ 0, the circles or the spiral of the ζ sum go around this point, although the sum itself does not approach it.

Why ζ(s) = η(s) / (1 − 2/2s)
ζ(s) − η(s) = 2·(1/2s + 1/4s + 1/6s + …)
           = (2/2s) · (1 + 1/2s + 1/3s + …) = (2/2s) · ζ(s)
so η(s) = (1 − 2/2s) · ζ(s).The even terms appear with + in ζ and − in η, so subtracting leaves twice the even terms. Since 1/(2k)s = (1/2s)(1/ks), the even terms add up to (1/2s)·ζ(s).
Key point: for complex s, the term 1/ns is an arrow of length 1/nσ, turned by the angle −t·ln n. The arrows add up to a finite value only for σ > 1. The formula η(s)/(1 − 2/2s) gives ζ for 0 < σ ≤ 1, and the functional equation gives it for σ ≤ 0.
