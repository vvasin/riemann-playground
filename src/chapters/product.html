Euler's product: how zeta is tied to the primes

Take s = 2. For each prime p, write a sum that uses only the powers of p:

for 2: 1 + 1/2² + 1/4² + 1/8² + …
for 3: 1 + 1/3² + 1/9² + 1/27² + …
for 5: 1 + 1/5² + 1/25² + …
and so on for every prime

Now multiply all of these sums together. To expand such a product, you pick one term from each sum and multiply the picks. For example, pick 1/4² from the first sum, 1/3² from the second, and 1 from all others. The result is 1/(4·3)² = 1/12².

Since 12 = 2² × 3 in only one way (step 1), the term 1/12² appears exactly once in the expansion. The same holds for every whole number n: 1/n² appears exactly once. So the product of all these sums is 1 + 1/2² + 1/3² + 1/4² + …, which is ζ(2).

Each of the sums is a geometric series: 1 + q + q² + … = 1/(1 − q) when −1 < q < 1. Here q = 1/p², so the sum for the prime p equals 1/(1 − 1/p²). The same argument works for any s > 1:

ζ(s) = 1/(1 − 1/2s) × 1/(1 − 1/3s) × 1/(1 − 1/5s) × 1/(1 − 1/7s) × …One factor for each prime. Valid for s > 1.

This formula, found by Euler, also shows that there are infinitely many primes. As s approaches 1, the left side grows without limit (step 3). A product of finitely many factors would stay finite, so the number of factors, and therefore of primes, must be infinite.

Key point: the sum over all whole numbers equals a product over the primes. This is why the zeta function carries information about primes.
