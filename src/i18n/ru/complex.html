В 1859 году Риман стал рассматривать s как комплексное число, s = σ + it. σ (сигма) — действительная часть, t — мнимая часть.

Что означает 1/ns для комплексного s

Степень с комплексным показателем нельзя вычислить повторным умножением. Её определяют через число e и натуральный логарифм: ns = es·ln n. При действительном s это обычная степень, потому что eln n = n. Степень числа e с мнимым показателем задаётся формулой Эйлера: eiθ = cos θ + i sin θ. Вместе это даёт

1/nσ+it = (1/nσ) · e−it·ln n,
e−it·ln n = cos(t ln n) − i sin(t ln n)В первой строке использовано 1/nit = n−it = e−it·ln n. Вторая — формула Эйлера при θ = −t·ln n.

Изобразим комплексное число a + bi стрелкой из 0 в точку (a, b). Стрелка длины r, направленная под углом φ к положительной действительной оси, — это число r·(cos φ + i sin φ). Углы измеряются в радианах, полный оборот равен 2π. Так как cos(−x) = cos x и sin(−x) = −sin x, слагаемое 1/ns — это стрелка длины 1/nσ под углом −t·ln n. Её длина зависит только от σ, а t только поворачивает её.

Сложение стрелок

Чтобы сложить комплексные числа, их стрелки прикладывают друг к другу: начало следующей к концу предыдущей. Так панель рисует сумму для ζ(s), по одной стрелке на слагаемое.

При σ > 1 сумма длин 1/nσ конечна (шаг 3). Тогда путь имеет конечную длину и приходит в одну точку — это значение ζ(s). При σ ≤ 1 сумма длин бесконечна, и повороты стрелок этого не исправляют. При σ = 1 и t ≠ 0 путь продолжает ходить по кругу. При σ < 1 он уходит наружу по расширяющейся спирали. При t = 0 все стрелки направлены вправо, и сумма растёт неограниченно, как на шаге 3. Во всех этих случаях у суммы нет значения. Поэтому сумма определяет ζ(s) только при σ > 1.

Продолжение дзета-функции за пределы суммы

Похожая ситуация возникает с геометрической прогрессией. Сумма 1 + q + q² + … имеет конечное значение только при −1 < q < 1, но формула 1/(1 − q) даёт значение для любого q, кроме 1. Для дзета-функции одна из таких формул использует знакочередующуюся сумму

η(s) = 1 − 1/2s + 1/3s − 1/4s + …Так как знаки чередуются, эта сумма имеет конечное значение при любом σ > 0.

Выберите на панели сумму η: каждая вторая стрелка направлена в обратную сторону, и путь приближается к одной точке.

При σ > 1 можно проверить, что ζ(s) = η(s) / (1 − 2/2s). Правая часть имеет смысл и при 0 < σ ≤ 1, и именно так ζ определяется в этой области. Знаменатель обращается в нуль там, где 2s = 2: при s = 1 и в точках 1 ± 2πik / ln 2 при k = 1, 2, 3, … При s = 1 функция ζ действительно обращается в бесконечность. В остальных этих точках η(s) тоже равна 0, и значение ζ в них равно пределу её значений в близких точках. Доказано, что продолжить ζ с сохранением гладкости (комплексной дифференцируемости) можно только одним способом, поэтому любая правильная формула даёт одни и те же значения. Другая формула, функциональное уравнение, продолжает ζ на область σ ≤ 0.

Панель отмечает значение ζ(s), которое даёт эта формула. При 0 < σ ≤ 1 и t ≠ 0 круги или спираль суммы для ζ идут вокруг этой точки, хотя сама сумма к ней не приближается.

Почему ζ(s) = η(s) / (1 − 2/2s)
ζ(s) − η(s) = 2·(1/2s + 1/4s + 1/6s + …)
           = (2/2s) · (1 + 1/2s + 1/3s + …) = (2/2s) · ζ(s),
значит, η(s) = (1 − 2/2s) · ζ(s).Слагаемые с чётными n входят в ζ со знаком +, а в η со знаком −, поэтому при вычитании остаётся удвоенная сумма этих слагаемых. Так как 1/(2k)s = (1/2s)(1/ks), сумма слагаемых с чётными n равна (1/2s)·ζ(s).
Главное: при комплексном s слагаемое 1/ns — это стрелка длины 1/nσ, повёрнутая на угол −t·ln n. Стрелки складываются в конечное значение только при σ > 1. Формула η(s)/(1 − 2/2s) задаёт ζ при 0 < σ ≤ 1, а функциональное уравнение — при σ ≤ 0.
