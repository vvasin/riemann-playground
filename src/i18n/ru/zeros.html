Нуль функции ζ — это такое значение s, при котором ζ(s) = 0. Нули бывают двух видов:

  • Тривиальные нули в точках s = −2, −4, −6, … Они следуют из функционального уравнения, полностью изучены и дальше не играют никакой роли.
  • Нетривиальные нули. Все они лежат в полосе 0 < σ < 1, которая называется критической полосой. Первый из них — точка s = ½ + 14,1347…i.

Выберите на панели шага 5 этот нуль и сумму η. Путь приближается к 0, поэтому η(s) = 0, а значит, ζ(s) = η(s) / (1 − 2/2s) = 0.

Нетривиальный нуль обычно обозначают ρ = β + iγ (ро, бета, гамма). Нули расположены симметрично: если β + iγ — нуль, то β − iγ, (1 − β) + iγ и (1 − β) − iγ тоже нули. На панели этого шага показана только верхняя половина (t > 0).

Главное: нетривиальные нули ζ — это точки β + iγ в критической полосе. У всех найденных до сих пор нулей β = ½.
