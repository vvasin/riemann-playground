Возьмём s = 2. Для каждого простого p запишем сумму, в которой участвуют только степени p:

для 2: 1 + 1/2² + 1/4² + 1/8² + …
для 3: 1 + 1/3² + 1/9² + 1/27² + …
для 5: 1 + 1/5² + 1/25² + …
и так далее для каждого простого числа

Теперь перемножим все эти суммы. Чтобы раскрыть такое произведение, из каждой суммы берут по одному слагаемому и перемножают выбранные слагаемые. Например, возьмём 1/4² из первой суммы, 1/3² из второй и 1 из всех остальных. Получится 1/(4·3)² = 1/12².

Так как 12 = 2² × 3 только одним способом (шаг 1), слагаемое 1/12² появляется в раскрытом произведении ровно один раз. То же верно для любого натурального числа n: 1/n² появляется ровно один раз. Поэтому произведение всех этих сумм равно 1 + 1/2² + 1/3² + 1/4² + …, то есть ζ(2).

Каждая из этих сумм — сумма геометрической прогрессии: 1 + q + q² + … = 1/(1 − q) при −1 < q < 1. Здесь q = 1/p², поэтому сумма для простого p равна 1/(1 − 1/p²). То же рассуждение работает для любого s > 1:

ζ(s) = 1/(1 − 1/2s) × 1/(1 − 1/3s) × 1/(1 − 1/5s) × 1/(1 − 1/7s) × …Один множитель для каждого простого числа. Верно при s > 1.

Эта формула, найденная Эйлером, показывает также, что простых чисел бесконечно много. Когда s приближается к 1, левая часть растёт неограниченно (шаг 3). Произведение конечного числа множителей осталось бы конечным, поэтому множителей, а значит и простых чисел, бесконечно много.

Главное: сумма по всем натуральным числам равна произведению по простым числам. Поэтому дзета-функция несёт информацию о простых числах.
