Фон Кох (1901) показал, что гипотеза Римана равносильна утверждению о подсчёте простых чисел. Шёнфельд (1976) записал это утверждение с явными числами:

Если гипотеза Римана верна, то для всех x ≥ 2657:
|π(x) − li(x)| < √x · ln x / (8π)Обратно, если это неравенство выполняется для всех x ≥ 2657, то гипотеза Римана верна. Здесь π — снова число пи.

Таким образом, гипотеза — это в точности утверждение о том, насколько далеко количество простых чисел может отойти от оценки li(x) из шага 2. Так как гипотеза теперь доказана, это неравенство выполняется для всех x ≥ 2657. Для сравнения: лучшие оценки, доказанные без гипотезы, намного слабее. Они меньше x лишь в такое число раз, которое растёт медленнее любой степени x, например медленнее √x или x0,01.

Панель показывает настоящие значения. В каждом случае фактическая погрешность намного меньше границы. Для x примерно до 1026 неравенство было доказано ещё до самой гипотезы, потому что нули, от которых оно зависит, были проверены на компьютере. Доказательство гипотезы распространяет его на все x.

Другие следствия

  • Промежутки между простыми числами: между x и x + C·√x·ln x всегда есть простое число, где C — фиксированная постоянная (Крамер, 1920).
  • Многие существующие теоремы: большое число результатов теории чисел было доказано в предположении, что гипотеза верна. Доказательство делает их безусловными: они больше не зависят от предположения.

Чего оно не даёт

  • Формулы, которая непосредственно выдаёт простые числа или n-е простое число.
  • Быстрого способа раскладывать большие числа на множители. Оно не позволит взломать шифрование вроде RSA.
  • Ответа на вопрос, является ли конкретное число простым. Для этого служат тесты простоты.
Итог: дзета-функция — это сумма по всем натуральным числам (шаг 3) и одновременно произведение по простым числам (шаг 4). Каждый из её нулей (шаг 5) добавляет одну волну к лестнице простых чисел (шаги 6 и 7). Размер этих волн зависит от действительных частей нулей. Гипотеза Римана утверждает, что все эти действительные части равны ½ (шаг 8). Это то же самое, что сказать: количество простых чисел никогда не отклоняется от li(x) больше чем примерно на √x · ln x. Гипотеза доказана в 2026 году.
