Чтобы связать нули с простыми числами, используют функцию подсчёта, немного отличающуюся от π(x). ψ(x) (читается «пси от x») — это лестница, которая поднимается в каждом простом числе и в каждой степени простого числа. Ступенька в степени p имеет высоту ln p:

x:    2    3    4=2²  5    7    8=2³  9=3² …
высота: ln2 ln3 ln2    ln5 ln7 ln2    ln3   …

Высоты ступенек ln p компенсируют то, что простые числа становятся реже (примерно одно из ln n, шаг 2), поэтому ψ(x) остаётся близкой к x. ψ содержит ту же информацию, что и π: каждую из них можно вычислить через другую. ψ используют потому, что формула для неё проще.

Риман (1859) и фон Мангольдт (1895) доказали точную формулу для ψ:

ψ(x) = x − Σρ xρ/ρ − ln(2π) − ½·ln(1 − 1/x²)Сумма Σ берётся по всем нетривиальным нулям ρ. Формула верна при x > 1. В точке ступеньки формула даёт середину ступеньки.

Кроме суммы по нулям, правая часть — гладкая кривая. Значит, каждую ступеньку лестницы создают нули.

Почему каждый нуль даёт волну

Для нуля ρ = β + iγ формула Эйлера даёт

xρ = xβ · xiγ = xβ · (cos(γ ln x) + i sin(γ ln x))

Если добавить слагаемое зеркального нуля β − iγ, мнимые части сокращаются. Вместе пара даёт действительную функцию

−2·xβ · (β cos(γ ln x) + γ sin(γ ln x)) / (β² + γ²)

Это волна. Два её числа играют разные роли:

  • Высота γ задаёт, как быстро волна колеблется. Колебания равномерны по ln x, а не по x.
  • Действительная часть β задаёт, как быстро растёт размах волны: пропорционально xβ. При β = ½ размах растёт как √x.
Главное: каждая пара нулей добавляет к лестнице простых чисел одну волну. Высота нуля задаёт частоту, действительная часть — скорость роста.
