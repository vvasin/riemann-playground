Чтобы связать нули с простыми числами, используют другую функцию, немного отличающуюся от π(x). ψ(x) (читается «пси от x», функция Чебышёва) — это ступенчатая функция («лестница»), которая совершает скачок в каждом простом числе и в каждой степени простого числа. Скачок в каждой степени p равен ln p:

x:    2    3    4=2²  5    7    8=2³  9=3² …
скачок: ln2 ln3 ln2    ln5 ln7 ln2    ln3   …

Высоты ступенек ln p компенсируют то, что простые числа становятся реже (примерно одно из ln n, шаг 2), поэтому ψ(x) остаётся близкой к x. ψ содержит ту же информацию, что и π: каждую из этих функций можно вычислить через другую. ψ используют потому, что формула для неё проще.

Риман (1859) и фон Мангольдт (1895) доказали точную формулу для ψ:

ψ(x) = x − Σρ xρ/ρ − ln(2π) − ½·ln(1 − 1/x²)Сумма Σ берётся по всем нетривиальным нулям ρ. Формула верна при x > 1. В точке скачка формула даёт середину ступеньки.

Все слагаемые правой части, кроме суммы по нулям, — гладкие функции. Значит, все ступеньки лестницы создаются нулями.

Почему каждый нуль даёт волну

Для нуля ρ = β + iγ по формуле Эйлера

xρ = xβ · xiγ = xβ · (cos(γ ln x) + i sin(γ ln x))

Если добавить слагаемое комплексно сопряжённого нуля β − iγ, мнимые части сократятся. Вместе эта пара нулей даёт действительную функцию

−2·xβ · (β cos(γ ln x) + γ sin(γ ln x)) / (β² + γ²)

Это волна. Два числа, задающих нуль, играют в ней разные роли:

  • Мнимая часть (высота) γ определяет, как быстро волна колеблется. Колебания равномерны по ln x, а не по x.
  • Действительная часть β определяет, как быстро растёт амплитуда волны: пропорционально xβ. При β = ½ амплитуда растёт как √x.
Главное: каждая пара нулей добавляет к лестнице простых чисел одну волну. Высота нуля задаёт частоту, действительная часть — скорость роста амплитуды.
